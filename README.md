# Customer Behavior Insight Dashboard

Analysis of customer behavior (funnel, retention, churn) using SQL and Python, 
visualized in an interactive Power BI dashboard — Data Analytics Bootcamp (Sprint 2).

## Business Problem
[ปัญหาธุรกิจของ workshop นี้คืออะไร — เช่น ธุรกิจอยากรู้ว่าลูกค้ากลุ่มไหน
มีแนวโน้ม churn สูง หรือ funnel ตรงไหนที่ลูกค้าหลุดมากที่สุด]

## Hypothesis
[ถ้ามี — เช่น "ลูกค้าใหม่มีอัตรา churn สูงกว่าลูกค้าเก่าอย่างมีนัยสำคัญ"]

## Data & Tools
- **Tools:** SQL (JOIN, Subquery, CTE), Python (pandas), Power BI
- **Data:** [ข้อมูลธุรกรรม/พฤติกรรมลูกค้าที่ใช้]
- **Data preparation:** Data quality checks and cleaning performed before analysis;
  data modeled using a Star Schema for structured reporting

## Approach
1. Designed a Star Schema to structure customer transaction data
2. Wrote SQL queries (joins, CTEs) to extract and validate customer behavior data
3. Analyzed behavior using Python (pandas): funnel stages, retention rate, churn rate
4. Built an interactive Power BI dashboard to visualize segments and trends

## Key Insight
[ผลลัพธ์จริงจาก workshop — เช่น กลุ่มลูกค้าไหน retention สูง/ต่ำสุด,
funnel drop-off เกิดตรงไหน]
